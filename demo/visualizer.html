Performance Insights

  • Pipeline Width: Firestorm's 8-wide pipeline is 2× wider than Icestorm, enabling higher instruction throughput.
  • Out-of-Order Window: Firestorm's ~330 entry ROB is 5.5× larger, allowing deeper speculation and better handling of long-latency operations.
  • Execution Resources: Firestorm has 2× the execution units, providing parallel execution capabilities for complex workloads.
  • Memory Operations: Firestorm supports 4.3× more in-flight loads and 3.3× more stores, crucial for memory-intensive tasks.
  • Register Files: Firestorm's larger register files (~5× for integer) reduce register pressure in complex code.
  • Latency: Both cores have similar instruction latencies, with Firestorm optimizing for throughput and Icestorm for efficiency.
