CPU Architectures

Compare Firestorm and Icestorm microarchitectures

🔥 Firestorm - High Performance Core

Designed for maximum single-threaded performance

Pipeline Width
8 uops/cycle
Integer Units
6 units
Load/Store Units
4 units
SIMD/FP Units
4 units
ROB Size
~330 entries
In-flight Renames
~623

Key Features

  • Advanced out-of-order execution with 8-wide pipeline
  • 14 total execution units for parallel instruction processing
  • Large reorder buffer for deep instruction window
  • Sophisticated instruction fusion (adds+branch, AES+EOR, etc.)
  • Zero-cycle register moves via renaming
  • Up to 11 issues per cycle in optimal conditions

❄️ Icestorm - High Efficiency Core

Optimized for power efficiency and background tasks

Pipeline Width
4 uops/cycle
Integer Units
3 units
Load/Store Units
2 units
SIMD/FP Units
2 units
ROB Size
~60 entries
In-flight Renames
~111

Key Features

  • Efficient 4-wide pipeline balanced for power and performance
  • 7 total execution units with smart resource allocation
  • Compact reorder buffer for reduced power consumption
  • Instruction fusion including unique MOVZ+MOVK elimination
  • ADR/ADRP elimination for address generation
  • Optimized for sustained throughput at low power

⚖️ Architecture Comparison

Firestorm vs Icestorm side-by-side

Feature 🔥 Firestorm ❄️ Icestorm Ratio
Pipeline Width 8 uops/cycle 4 uops/cycle 2.0×
Integer Units 6 3 2.0×
Load/Store Units 4 2 2.0×
SIMD/FP Units 4 2 2.0×
Total Execution Units 14 7 2.0×
ROB (Coalesced) ~330 entries ~60 entries 5.5×
In-flight Renames ~623 ~111 5.6×
Int Register File ~380-394 ~79 4.9×
FP/SIMD Register File ~432 ~87 5.0×
In-flight Loads ~130 30 4.3×
In-flight Stores ~60 18 3.3×

Performance Characteristics

Firestorm delivers approximately 2× the execution throughput of Icestorm with significantly larger out-of-order windows. However, Icestorm achieves impressive efficiency through smart design choices like instruction elimination and fusion, making it ideal for background tasks and power-constrained scenarios.
